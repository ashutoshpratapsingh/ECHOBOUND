# Gameplay Demonstration Video & Capture Guide

This guide provides instructions for recording, demonstrating, and evaluating **ECHOBOUND: Realms of Echo** across all 3 levels.

---

## 1. Fast Screen Recording Instructions

### Option A: Windows Xbox Game Bar (Recommended, Zero Installs)
1. Launch the game by double-clicking `start-game.bat` (or opening `index.html`).
2. Press `Win + Alt + R` to start recording immediately.
3. Play through the demonstration sequence outlined below (approx. 60–90 seconds).
4. Press `Win + Alt + R` to finish recording.
5. The video file will be saved directly in your Windows `Videos\Captures` folder as an MP4.

### Option B: OBS Studio / Chrome Tab Recorder
1. In OBS, select **Window Capture** or **Browser Source** at 1920x1080 @ 60 FPS.
2. Enable desktop audio to capture the synthesized Web Audio SFX (Echo ping, jump whoosh, crystal chimes, snake hisses, victory fanfare).

## 3. Key Moments Evaluators Look For
1. **The Echo Pulse**: Notice how the pulse serves both as a path-revealing tool over chasms AND as a non-lethal defense against the Anaconda Guardian.
2. **Boss Interaction**: Watch the Anaconda’s head recoil backwards into a dazed state when hit by the Echo Pulse wave.
3. **Responsive Controls**: Test on desktop keyboard or with mouse clicks on the on-screen mobile D-pad and action buttons.
4. **Zero-Latency Audio**: Listen to the procedural audio engine synthesizing jump whooshes, sonar chimes, and fanfare in real time.
